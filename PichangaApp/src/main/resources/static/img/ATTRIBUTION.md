## Tipografías

- **Archivo** — Omnibus-Type, SIL Open Font License 1.1.
- **Inter** — Rasmus Andersson, SIL Open Font License 1.1.

Ambas se sirven localmente desde `/fonts` para que la aplicación funcione sin conexión.

## Cómo sustituir por fotos propias

1. Guarda la foto en `src/main/resources/static/img/canchas/` con el mismo nombre de archivo.
2. Usa formato horizontal, mínimo 1200 px de ancho y peso menor a 400 KB.
3. Actualiza esta tabla con el autor y la licencia.
